# Exchange API endpoints this SDK implements with a typed method, against the
# spec version pinned in .api-version. Hand-maintained source of truth for
# coverage. The Python SDK deliberately trails the Rust SDK — add a line when
# you add a typed method. Format: METHOD /path  ({market_id} = placeholder)
#
# Machine-checked, both ways, by scripts/check_spec_drift.py on every PR: every
# line here must exist in the pinned spec, and must have a caller in the client
# code — no more, no less. There is no third category: an operation the pinned
# spec does not define is not implemented at all (ENG-8616), so the checker's
# CODE_ONLY_OPS allowlist is empty and any entry in it fails the run. Every line
# here is a real contract operation, and the coverage figure counts nothing else.
#
# Every request goes to the one REST base (the spec's `/v1`) plus the bare
# spec path, and is signed over that path (EDR-006, ENG-18322). The bridge reads
# alone keep the `/api/v1` spelling: the pinned spec has no bare twins for them
# yet. The prefix is part of the operation, so a line carries it whenever the
# call does.
